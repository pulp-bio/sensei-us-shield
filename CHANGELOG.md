## [1.0.0] - 2026-09-04

### Added

- Initial WULPUS PRO ultrasound shield release for BioGAP-Ultra.
- Altium design sources and released schematic, assembly, BOM, Gerber, drill, and pick-and-place files.
- MSP430FR5043 firmware for 16-channel ultrasound control, acquisition, and BioGAP host communication.
- Runtime control of the pulser, high-voltage multiplexer, receive path, time-gain compensation, envelope detector, and power domains.
- BioGUI acquisition workflow and dedicated BioGAP-Ultra/WULPUS PRO interface documentation.
